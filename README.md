# MediVault - Secure Medical Data Storage

A Flutter application for securely storing and managing medical data using Firebase as the backend.

## Firebase Configuration

To build and run this project, you will need to create a Firebase project and add the configuration file to the project. Follow these steps to create a Firebase project and add the configuration file:

1. Go to the [Firebase Console](https://console.firebase.google.com/).
2. Click on the "Add project" button and follow the instructions to create a new project.
3. Once the project is created, click on the "Add app" button and select the Android platform.
4. Register the app with the package name `com.ensas.medivault`.
5. Follow the prompts to download the `google-services.json` file and add it to the `android/app` directory in the project.
